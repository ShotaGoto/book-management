# ADR-0002: 書籍管理の中核機能

- **日付:** 2026-06-10
- **ステータス:** 採用済み

## コンテキスト

初期実装はタイトルによる追加・削除のみ。書籍管理ツールとして最小限必要な機能を定義する。

## 決定

### 書籍モデルの拡充

| フィールド | 型 | 概要 |
|---|---|---|
| title | TEXT NOT NULL | 書籍タイトル |
| author | TEXT NOT NULL DEFAULT '' | 著者 |
| status | TEXT NOT NULL DEFAULT 'unread' | 読書ステータス (unread / reading / done) |
| memo | TEXT NOT NULL DEFAULT '' | 自由メモ |

### API エンドポイント追加

- `PUT /api/v1/books/:id` — status・memo の更新

### フロントエンド機能

- 書籍追加フォームに著者入力を追加
- 一覧にステータスバッジ・著者を表示
- ステータスでタブフィルタリング（すべて / 未読 / 読書中 / 読了）
- ステータスをインラインで変更

## 理由

- ステータス管理が書籍管理ツールの核心
- メモは読後の記録として必須
- 著者は検索・識別に必要
- タブフィルターで読みたい本・読書中の本を素早く確認できる
